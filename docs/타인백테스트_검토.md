# 타인 백테스트 검토 — 주도주 종가베팅 2종

외부에 공개된 단타 알고리즘 두 개의 백테스트 결과를 검토했다.
**결과 수치는 우리와 비교 대상이 아니다**(연 1,000건 일봉 단타 vs 월 1회 재무 스크리너).
가져올 것은 **검증 절차**와 **실패 원인의 구조**다.

## 요약

| | 1번 알고리즘 | 2번 알고리즘 |
|---|---|---|
| 진입 | 섹터 신고가 + 수급 + 프로그램 순매수 | 분봉 박스권 돌파 + 거래대금 |
| 기간 | 2022-01 ~ 2026-07 | 2022-01 ~ 2026-07 |
| 거래 | 3,210건 | 597건 |
| 총수익률 | **-45.0%** (CAGR -13.6%) | +36.3% (MDD -14.0%) |
| 결론 | 필터 그리드로 개선 시도 | 통계적 엣지 입증 실패 (p=0.12) |

두 알고리즘은 진입 조건이 달라도 **같은 베팅**이다 — 종가 매수 후 익일 시가 청산,
즉 오버나잇 갭. 게시자 본인이 "익일 갭업이면 수익, 갭다운이면 손실, 갭 크기는
랜덤에 가깝다"고 인정했다.

## 1번 알고리즘 — 승률이 아니라 손익비 문제

손익분기 승률 = 평균손실 / (평균수익 + 평균손실)

| 연도 | 실제 승률 | 손익분기 승률 | 격차 | 기대값/건 |
|---|---|---|---|---|
| 2022 | 32.5% | 54.3% | -21.8p | -0.704% |
| 2023 | 35.5% | 43.7% | -8.2p | -0.316% |
| 2024 | 37.0% | 45.5% | -8.5p | -0.305% |
| 2025 | 34.8% | 40.1% | -5.3p | -0.185% |
| 2026 | 37.9% | 29.4% | **+8.5p** | +0.475% |

승률은 5년 내내 32~38%로 거의 고정. 움직인 건 손익분기선이다.

### 2026 흑자전환 분해

```
2025 실제                 -0.185%
2026 실제                 +0.475%
승률만 2026으로 교체       -0.076%   <- 여전히 적자
손익폭만 2026으로 교체     +0.302%   <- 이것만으로 흑자

기여도:  승률 +0.109%p  vs  손익폭 +0.487%p  (4.5배)
```

신호가 좋아진 게 아니라 **평균수익이 2.11% -> 3.94%로 두 배가 된 것**이 전부.
게시자 스스로 "급등주 출현 빈도 일평균 1.4건으로 폭발"이라고 기록했다.
전략 변수가 아니라 **시장 상태 변수**다.

### 결정타 — 4단계

```
B. 양봉만              +0.64%
C. B + 종가 1,000원↑   +0.47%
D. C + 상한가 제외     -0.11%   <- 부호 반전, MDD -83.4%
```

5단계에서 29%+(상한가) 구간이 승률 73.0% / 평균 +7.72%인데,
게시자가 그 칸에 직접 `(매매불가)`라고 적었다. 상한가에는 매도 잔량이 없어 살 수 없다.

**이 전략은 살 수 없는 종목으로만 돈을 번다.**

상승률 구간별 패턴도 비단조라 잡음에 가깝다:
0~5% (-0.18%) / 5~10% (-0.00%) / 10~15% (+0.24%) / 15~20% (+0.42%) /
20~29% (**-0.08%**) / 29%+ (+7.72%, 매매불가)

### 표 무결성 문제

2단계와 4단계의 거래수가 전 행 5,455건으로 동일하다.
`외국인>0` 필터를 걸었는데 건수가 안 줄고, AND 조건과 OR 조건이 같은 건수다.
**논리적으로 불가능하다.** 1단계 값이 복사됐거나 필터 미적용 버그.

3단계는 반대로, 매도 시각만 바꿨는데 거래수가 5,355 -> 5,474로 변한다.
진입 조건이 같으면 건수는 변할 수 없다.

-> 이 열이 틀렸다면 2~5단계 결론 전부가 재검증 대상.

## 2번 알고리즘 — 게시자가 스스로 정답을 냈다

t 검정 재현 결과 게시자 수치와 일치했다.

```
표본 597건 · 평균 +0.28% · 표준편차 4.49%
t = 0.28 / (4.49/sqrt(597)) = 1.52   (p=0.12)

이 엣지를 입증하는 데 필요한 표본
  유의성만 (검정력 0%)     987건  ->   7.4년
  검정력 80%             2,014건  ->  15.1년
  검정력 90%             2,697건  ->  20.3년
```

**앞으로 15년을 더 매매해야 판단이 선다.** 사실상 검증 불가능한 전략.

게시자가 짚은 세 가지는 모두 타당하다:

1. **클러스터 보정 후 p=0.42** — 같은 날 여러 종목은 독립이 아니다.
   아마추어 백테스트에서 이 보정을 스스로 하는 경우는 드물다.
2. **연 표준편차 ±38.0% vs 연평균 +13.6%** — 샤프 0.36.
3. **대박 6건(1.0%)이 수익의 전부** — 빼면 마이너스.
   즉 **수익의 유효 표본이 n=6**이다. 597이라는 숫자는 착시.

거래비용: 세전 +0.59% -> 세후 +0.28%. **엣지의 53%가 비용으로 소멸.**

## 두 글이 공통으로 놓친 것

**벤치마크 열이 없다.** 게시자 본인이 "시장이 좋으면 눈감고 사도 수익이 난다"고
써놓고 KOSPI 대비 초과수익을 표에 넣지 않았다. 2026년 +32.8%가 시장이 +40% 오른
해의 결과라면 그건 -7%p 손실에 MDD -31.6%를 얹은 것이다.

**포지션 크기 미명시.** 총수익률에서 역산하면 두 글 모두 종목당 15~20%
(동시보유 5~7종목)를 가정하고 있다. 명시가 없으면 +503.5%든 +233,120%든
가정 하나로 자릿수가 바뀐다. **평균순익이 훨씬 견고한 열이다.**

**결론부의 "경험과 재량이 필요하다"** 는 정직한 고백이지만 동시에 이런 뜻이다 —
재량이 필요하다면 백테스트는 그 전략을 검증한 적이 없다.
검증된 것은 재량 없는 규칙이고, 그 규칙의 성적은 -45%였다.

## 우리 백테스트에 반영할 항목

| 항목 | 우리 버전 |
|---|---|
| 연도별 t·p 분해 | IC +0.059가 어느 해에 몰렸는지 |
| 상위 소수 종목 기여도 | 상위 5종목 빼면 초과수익이 남는가 |
| 날짜 클러스터 보정 | 월별 코호트 중복 보정 |
| 손익분기 승률 | 월별 승률 vs 손익비 |
| 세전/세후 분리 | 수수료·세금·슬리피지 |
| **매매불가 종목 배제** | 거래정지·관리종목·유동성 부족 제외 버전 |
| 필요 표본 계산 | 몇 년 더 있어야 입증되는가 |
| **벤치마크 열** | KOSPI 대비 초과수익 (저 글이 빠뜨린 것) |

## 가져오지 않을 것

- **순차 그리드 서치** — 1~5단계를 이어붙이면 탐색 공간이 1,900개가 넘는다.
  모멘텀(-0.003)과 3년 CAGR(-0.029)에서 이미 배운 실수.
- **총수익률(복리)을 헤드라인으로 쓰기** — 포지션 가정에 종속된다.
- **진입 로직 전체** — 분봉·신고가·프로그램 순매수는 우리 설계 원칙(재무제표 기반)과
  무관하고, 사용자가 명시적으로 차트 기법을 제외했다.
